# Phase 3.1 package map -- which package each flat default-package class moves INTO.
#
# Format: Class=package, one class per line (same shape as renames-3.3.txt, so the
# two maps are read the same way and reviewed the same way).
#
# Every one of the 131 top-level default-package classes must appear EXACTLY once.
# MoveToPackages aborts if any is missing, duplicated, or if any class would be left
# in the default package -- because a class in a NAMED package cannot see a type in
# the DEFAULT package at all (the default package is not importable), so a partial
# move does not compile.  Note `signlink` is deliberately ABSENT: it already lives
# in `sign` and does not move.
#
# The partition is the one agreed and verified on 2026-10-04 (131/131, no duplicates,
# none missing) and recorded in CLIENT_REFACTORING_PLAN.md's Phase 3.1.
