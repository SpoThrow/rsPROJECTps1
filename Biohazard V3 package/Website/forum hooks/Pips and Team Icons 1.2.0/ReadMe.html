Pips and Team Icons 1.2.0

Description

Whenever a member has a Team Icon, that always shows below their avatar in posts instead of the pip images. With this hook, members who have Team Icons will also display the pip image(s) associated with the number of posts they have made directly below their Team Icon.

File Information

  • Compatibility: IP.Board 3.x.x - Yes
  • Author: Lewis Putz (Originally by Michael McCune)

Step 1: Import the Hook File

Log in to your IP.Board Admin CP and visit the System tab -> Applications & Modules -> Manage Hooks page. In the 'Install a New Hook' section, browse to the XML file included with these instructions and click Open.

Step 2: Change Hook Settings (Optional)

You can optionally hide pips for specific groups alongside their team icons, and optionally choose to have pips above the team icons instead of below. You can change these settings by visiting your IP.Board Admin CP -> System tab -> System Settings page. Click on the 'Hooks' tab, followed by 'Pips and Team Icons'.
