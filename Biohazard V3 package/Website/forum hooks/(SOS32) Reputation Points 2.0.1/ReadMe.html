Description

This app will show top reputation points of IP.Board.

Step 1: Upload Files

Upload all of the contents of the Upload folder to your forums, preserving the directory structure.

Step 2: Install the Application

Once you have uploaded all of the files, visit the Manage Applications & Modules page on the System tab of your Admin CP and click the link to Install this application.

Step 3: Application's Settings

Click on Other Apps tab and you'll see Reputation Points. Click on Settings to configure the application as you wish.
